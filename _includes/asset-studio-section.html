Asset Studio

Asset Studio is a browser-based environment for bringing your ideas to life with a single prompt.

Supported Products

  • IBM watsonx Orchestrate
  • IBM watsonx.ai
  • IBM Planning Analytics
  • IBM Cloud Object Storage
  • Elastic Search
    • ... and more

What you can do

  • Create worflows, agents or apps with just a prompt description.
  • Open the live preview when deployment is available.
  • Switch to code view to inspect generated files.
  • Open GitHub, download code, or update the asset.
